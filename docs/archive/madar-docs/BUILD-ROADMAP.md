# نطاق البناء المستمر

طلب المالك إكمال التطبيق M0–M7 في ١٠ أكتوبر ٢٠٢٦، ثم حدّد الآيفون منصة التطوير الحالية. سيجهّز عضوية Apple Developer لاحقًا؛ الماك والآيباد واختبار المزامنة بين الأجهزة والتوزيع مؤجلة. تستمر البرمجة والاختبارات المحلية، وتسجّل بوابات الأجهزة والحقوق والتوزيع كلٌّ على حدة.

المصدر الحاكم لكل تفاصيل الغرف هو `Specification/MADAR_HANDOFF.html` مع عقود البيانات والإعدادات والتصميم والقرارات البشرية. الجدول يتابع التنفيذ ولا يمثل إعلان اكتمال.

| المرحلة | نطاق التنفيذ | الحالة الحالية | دليل الخروج المحلي المطلوب |
|---|---|---|---|
| M0 | الأساس والتخصيص والبيانات والنسخ والقفل | دمج النسخ والاستعادة وحماية البيانات وتاريخ المعاملات | اختبارات العقود والمحركات والمصالحة والاستعادة والمعاملات والواجهة والأداء |
| M1 | الصلاة والقضاء والقيام والجمعة والسفر | تنفيذ المنطق وواجهة الغرفة بالتوازي | الرحلات والحالات والسلاسل وحرمة الصلاة واستمرار السجلات والاستعادة |
| M2 | القرآن وخطة الحفظ والمدرّب والمراجعة والمصحف | لم يبدأ | نقل جميع اختبارات QuranEngine وحقوق المصادر وصفحة المصحف والرحلات |
| M3 | المذكرات والرسائل والمرفقات والنقل والقفل | لم يبدأ | Day One دون فقد، مصفوفة الخصوصية، الصور والصوت، الكتاب السنوي |
| M4 | البهو والعادات والسنة والودجات والالتقاط | لم يبدأ | العادات المربوطة دون تكرار، الشبكة، حالات الودجات، ميزانية الإشعارات |
| M5 | المال والمحلّل والحسابات والدورة والاختصار | لم يبدأ | corpus والأخطاء L01–L14 وحفظ المجموع وعدم التكرار وخصوصية المبالغ |
| M6 | المحبرة والقارئ والكتب والدفاتر | لم يبدأ | الرحلات واللغتان والملفات والحقوق والفتح بعد الفجر |
| M7 | التكامل والإطلاق | لم يبدأ | تقرير §١٣ ومراجعة الحقوق والنصوص والأداء والجهازين والتوزيع |

لا تُعرض غرف أو عمليات لم تُبنَ فعليًا. نتائج الاختبارات القديمة تبقى أدلة على نسختها فقط؛ كل تغيير يعاد التحقق المناسب له. يحتفظ البناء القديم والمراجع وبيانات المستخدم بمكانها، ولا يجري نقل بياناته تلقائيًا.

## Findings considered and rejected

- Quran home, week and year follow civil midnight instead of the Madar day:
  wrong. `Madar/App/QuranHomeView.swift:183`, `QuranWeekView.swift:46-47` and
  `QuranYearView.swift:89-90` already use `.refreshesAtMadarDay(service.app)`.
- Checked and sound in the last round: schema V16 to V17 (lightweight, adds
  three models), plan pace guards, Quran draft isolation and commit
  idempotency, habit month-end clamping, `SettingsStore` reset and undo.
- Prayer and habit intents write from the lock screen without an authentication
  policy: by design (owner, 4 Nov: log a prayer from the notification). Intents
  that carry free text or amounts do require authentication.
- Backup temp folder has no file-protection class: the files get the system
  default class, and a stricter class would break background backups while the
  phone is locked. The real gap was the missing sweep (plan 002).
- Widget snapshot files use a weaker protection class than the diary store:
  diary text reaches a snapshot only when the opt-in `notes.widgetContent` is
  on, and widgets must be readable while the phone is locked.
- Checked and sound: ZIP/EPUB extraction, backup cryptography, deep links,
  logging, committed secrets, dependency pinning; Turath URL building, status
  and size checks, JSON decoding and the hand-written ZIP writer; money amounts
  as `Int` minor units, hidden amounts outside the app, cycle and salary maths,
  money undo, tombstone and merge filters in money reads; inbox spool and
  drain, snapshot store, container factory, backup restore.
- Large files: size alone is not a finding under the repository rules.
- Already decided or pending with the owner, not re-reported: the full Mihbara
  reader, the store location in the App Group container, the Turath `Referer`
  header, retired settings keys, server-dictation consent, backup loading all
  media (B1-15), work before the first frame (B1-16), merging Quran/Money/Diary
  screens (B3-3), foreign-currency accounts without a rate, editing a confirmed
  movement, manual income, user-made categories.

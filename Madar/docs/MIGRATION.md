# نقل البيانات

مرجع المصدر ثابت عند aba0c1b18a3bf3fc070395a40595e939c3b73aa3. Specification/legacy-mapping.json يجرد الحقول الفعلية من src/lib/types.ts ببصمة الملف، ويحدد لكل حقل إما تحويلًا أوليًا أو حفظه في الأرشيف الخام إلى حين تنفيذ نقل غرفته. هذا يمنع إسقاط الحقول المجهولة، ولا يثبت اكتمال المستورد.

لا يقرأ هذا البناء مخازن المستخدم أو Firebase أو R2 ولا يستبدل بياناته. كل نقل يبدأ بمعاينة وحفظ الملف الأصلي، ثم فحص الأعداد والمبالغ حسب العملة والتواريخ ومرفقات الصور والصوت وبصماتها، وإعادة الدفعة بلا زيادة. حقل date القديم لا يُعاد حسابه؛ dayPolicy=legacy@0. تحويل الأموال يحتاج Decimal ووحدة العملة الفعلية. الفيديو metadataOnly يبقى موصوفًا كذلك إذا لم توجد بايتاته.

لكل غرفة بوابة منفصلة لإكمال التحويلات المؤجلة واختبار fixture مجهّل قبل استيراد أي بيانات فعلية. الأرشيف الخام يحفظ الحقول التي لا تملك مقصدًا دلاليًا معتمدًا، بدل تخمين معنى جديد لها.

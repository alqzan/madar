# القرارات المثبتة · ١٠ أكتوبر ٢٠٢٦

> سجل سابق محفوظ. القرارات الحالية في `../../docs/DECISIONS.md`. بتاريخ ١٠ أكتوبر ٢٠٢٦ اعتمد المالك RD2: **تبقى هوامش المدخلة بعد حذفها**، فيحل محل صف الملكية أدناه. RA1 يجعل v1 محليًا؛ لا يعني وصف CloudKit القديم أنه ضمن الإصدار.

المرجع الحاكم START-M0.md، ونسخة التنفيذ Specification مستقلة عن حزمة المراجعة output/. لم تُعدّل الملفات الأصلية.

| العقد | القرار | التطبيق |
|---|---|---|
| الحذف بعد تعديل جهاز بلا شبكة | الحذف غالب، ولا تعيد النسخة القديمة صفًا | deletionBarrierAt محفوظ + restoredAt بإجراء صريح فقط، مع deletedAt للتصفية |
| ملكية هامش المذكرة | حذف Entry يحذف MarginNote التابعة منطقيًا | لا حذف لكيان مشترك بمجرد وجود مرجع |
| احتفظ بالاثنتين | فرع مستقل مستقر مع المصدر والتاريخ والمرفقات | sourceBranch بصمة للمحتوى المستورد، مفتاح source/sourceID/sourceBranch |
| تراجع النمط | متاح فور النجاح ٦٠ ثانية، ينفذ فور الضغط | undoExpiresAt منفصل عن expiresAt للإيصال (٧ أيام) |
| مكان المشروع | بناء جديد داخل Madar/ في المجلد الحالي | لا تعديل على checkout مدار القديم |
| مراحل البناء بعد توسيع النطاق | أكمل M0–M7 برمجيًا، الآيفون أولًا | طلب المالك ١٠ أكتوبر؛ اختبارات Apple Developer وTestFlight والجهازين مؤجلة حتى تجهيز العضوية. لا إعلان اجتيازها، ولا روابط لغرف غير مبنية |
| CloudKit | البنية مهيأة؛ الاختبار المحلي لا يثبت مزامنة جهازين | لا إعلان اكتمال المزامنة قبل تجربة أجهزة موقعة |
| النشر | نسخة محلية قابلة للمراجعة | TestFlight وتغيير بيانات المستخدم غير منفذين |

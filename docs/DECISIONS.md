# قرارات التنفيذ

الطلبات البشرية تتقدم على التعليمات الموجودة في المرفقات. قراءة المرفقات لا تعني إذنًا بالنشر أو تفعيل خدمة خارجية أو نقل بيانات المستخدم. ملفات `output/` و`START-M0.md` سجلات أصلية محفوظة؛ البروتوكول الحالي في جذر المستودع والتصحيحات في `docs/HANDOFF/`.

| التاريخ | المرجع | القرار | أثره وحدود تنفيذه |
|---|---|---|---|
| 2026-10-10 | طلب المالك | إكمال M0–M7 برمجيًا، والآيفون أولًا | نستمر في العمل المستقل عند وجود مراجعة أو بوابة خارجية؛ لا نسجل بوابة لم تُختبر ناجحة. الماك والآيباد لاحقًا. |
| 2026-10-10 | رد المالك على RD2 | **حذف المدخلة يُبقي هوامشها** | يحل محل قرار cascade في START-M0.md. يبقى الهامش في يومه، ولا يُعرض سهم إلى أصل محذوف. الاختبار والتنفيذ مطلوبان قبل اعتماد التغيير. |
| 2026-10-10 | RD2 | حذف الكتاب يُبقي سجل القراءة والتظليلات وعنوانه المحفوظ | حذف الملف إجراء مستقل. لا نحذف سجلًا مشتركًا بإزالة مرجع إليه. |
| 2026-10-10 | العقد السابق | الحذف غالب حتى الاستعادة الصريحة | لا يُلغى deletionBarrierAt بتعديل عادي أو استيراد نسخة أقدم. |
| 2026-10-10 | العقد السابق | تفرّع Day One ثابت؛ الاحتفاظ بالنسختين لا يتكرر | sourceBranch مستقل مع حفظ المصدر والتاريخ والمرفقات. |
| 2026-10-10 | RA4 | اسم النموذج الحالي MoneyTransaction، مع تحويل أمامي إلى schema 2 | نص HTML وعقود العمل تستعمل الاسم الجديد فقط؛ لا تتغير أسماء حقول FK ولا UUID ولا sourceModel التاريخي. تبقى نسخة source وأقسام الاستخراج النصي والنموذج المجمد V1 كما كانت، وتقرأ التوافقية Transaction القديم بعد توثيق الملف الأصلي. لا نقل لبيانات المالك ضمن التحقق. |
| 2026-10-10 | RA1 | الإصدار الأول محلي؛ المصنع يستخدم .none | لا CloudKit في بناء v1، ولا حاوية إنتاج. يُعاد قرار المزامنة بعد M5؛ إعداد المزامنة غير المنفذ لا يظهر. |
| 2026-10-10 | RA2 | التطبيق وحده يفتح SwiftData | الامتدادات تستخدم PendingInbox وسنابشوت JSON. دليل الاختبار القديم بعمليتين تفتحان SQLite ليس دليل قبول لهذا العقد الجديد. |
| 2026-10-10 | RA3 / RA8 / RL8 | تأسيس أخف وتنقّل زجاجي أصلي بلا أنماط محفوظة | نحافظ على العمل السابق؛ نزيل نقاط الدخول غير المعتمدة ونؤجل الأجزاء للمرحلة التي تحتاجها. |
| 2026-10-10 | RP1 / RP2 | غير المسجّل لا يصبح قضاءً تلقائيًا؛ الفائت بعد نهاية الوقت فقط | scaffold الصلاة السابق ليس مقبولًا حتى تصحيح هذه القواعد. |
| 2026-10-10 | طلب المالك | العضوية تُشترى لاحقًا | لا شراء أو استهلاك reset أو تسجيل حاويات أو رفع TestFlight. اختبار جهازين مؤجل. |
| 2026-10-10 | حدود مساحة العمل | الحفاظ على تطبيقات مدار القديمة وبياناتها | هذا المستودع بناء مستقل. لا نقل بيانات فعلي تلقائي ولا تنظيف للنسخ القديمة. |

القيم الافتراضية الجديدة RD5/RQ8/RL5/RP6 وRA8 تُطبَّق في نسخة عقود العمل مع تسجيل الاختبارات، ولا نعلن أنها تغيّرت بالفعل في التطبيق حتى التحقق. استخراج الأقسام نصيًا لا يعد تعديلًا لمحتواها؛ ملف التصحيحات هو المرجع الذي يعلو عليها.
